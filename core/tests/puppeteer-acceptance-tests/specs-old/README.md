# Puppeteer Acceptance Tests File Structure.

All Old Acceptance tests are moved to `/specs-old/` in puppeteer-acceptance-tests folder. This is because we are moving to [CUJv3 Doc](https://docs.google.com/document/d/1D7kkFTzg3rxUe3QJ_iPlnxUzBFNElmRkmAWss00nFno/edit?tab=t.0#heading=h.3qx2l2dkg3vx). All of the new tests should be written in `/specs/` folder and should be in sync with the same doc.

Additionally, when moving tests from `/specs-old/` to `/specs/`. Update it's status in v3 Doc above.
